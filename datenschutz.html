Datenschutzerklärung

Diese Website ist eine private Informationsseite für rclone-backup. Private Sicherung eigener Dateien in einem eigenen Google-Drive-Konto mithilfe von rclone. Sie ist kein Angebot für Dritte.

Verarbeitung auf dieser Website

Diese Seiten enthalten keine Formulare, keine Analyse- oder Werbedienste, keine Cookies, keine eingebetteten Inhalte und keine eigenen Skripte. Über diese Website werden keine Google-Zugangsdaten, Dateien oder Sicherungsinhalte entgegengenommen oder gespeichert.

Google Drive und rclone

Die für das private Backup erforderliche Google-Autorisierung erfolgt außerhalb dieser Website in der lokalen rclone-Umgebung. Zugangstoken und Daten aus Google Drive werden nicht an diese Website übertragen.

Hosting

Die Seiten werden über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet GitHub technisch erforderliche Verbindungsdaten, etwa IP-Adresse und Abrufzeit, nach den eigenen Datenschutzbestimmungen.
